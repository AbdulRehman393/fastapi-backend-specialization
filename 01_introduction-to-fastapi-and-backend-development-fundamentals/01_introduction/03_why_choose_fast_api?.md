### Framework Comparison: Django vs. Flask vs. FastAPI

| Feature | Django | Flask | FastAPI |
| :--- | :--- | :--- | :--- |
| **Architecture** | Heavy, structured, built-in tooling | Lightweight, minimalistic | Modern, API-focused |
| **Performance** | Moderate | Moderate | High (Native Async support) |
| **Data Validation**| Requires ORM/Forms | Manual implementation | Native via Pydantic & Type Hints |
| **Documentation** | Not supported out-of-the-box | Not supported out-of-the-box | Native OpenAPI (Swagger UI) |
| **Security/Auth** | Built-in | Minimal / Third-party | Built-in tools for OAuth2 & JWT |
| **Best For** | Full-stack monolithic apps | Small, simple web apps | High-performance scalable APIs |
